## Pizza Menu

An interactive pizza ordering menu where users can select from different pizza options and toppings. The application processes the user's selections and dynamically calculates the total cost of the order.

This project focuses on handling user input, working with JavaScript logic, and updating the page based on the user's selections.

---

## Tic-Tac-Toe Game

A browser-based version of the classic Tic-Tac-Toe game for two players. Players can choose their preferred game tokens and take turns placing them on the board.

The game includes turn management, win detection, and a celebratory result when a player wins.

---

## Calculator

A simple and functional calculator designed to perform basic arithmetic operations.

Users can perform addition, subtraction, multiplication, and division through an easy-to-use web interface.
